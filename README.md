This PSP file sharing network is a middle ground between a P2P sharing network and a client-server file sharing network. The server shares the initial file with all clients and then deletes the file.
Now all clients start requesting for chunks they do not have. The server has an LRU cache of size N, where N is the number of clients. Each chunk is of 1KB. In case of a cache miss, the server broadcasts to all clients to reply with the chunk. The client which has it replies with it.
All messages are shared over UDP and all data transfer happens over TCP. The server spawns a worker thread for each request. The clients have a sister thread which listens to broadcasts and replies with the chunk. The sister thread too, spawns a worker thread to transmit the chunk (only if the client has the chunk), this is so that the sister's threads UDP buffer doesn't overwhelm with requests.
Clients verify their file at the end using MD5 hash. The simulation ran in ~100 seconds for N=100. The shared file was of 115KB.
